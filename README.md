# DataFrameReporter — отчёт о состоянии DataFrame

Утилита для быстрой первичной проверки табличных данных: один запуск — и вы видите
размеры таблицы, дубликаты, пропуски и статистику describe(), без ручного набора
десятка команд pandas.

## Какую проблему решает

При старте анализа данных (EDA, Exploratory Data Analysis — разведочный анализ
данных) почти всегда нужно ответить на одни и те же вопросы:

* сколько в данных строк и столбцов?
* есть ли дубликаты и какая их доля?
* сколько пропусков и где?
* как выглядят базовые статистики?

Класс `DataFrameReporter` (файл `src/reporter.py`) решает эту задачу: метод
`show_report()` собирает весь отчёт одним вызовом и печатает его в консоль.

## Возможности

* количество строк и столбцов DataFrame;
* количество и доля дубликатов;
* статистика `describe()`: только числовые столбцы или все сразу;
* количество и доля пропусков во всём датафрейме;
* настраиваемые форматы вывода:
  * `float_format` — формат чисел с плавающей точкой;
  * `percent_format` — формат процентов;
  * `include_all` — выводить `describe()` по всем столбцам.

## Установка окружения

Требуется Python 3.10+.

1. Клонируйте репозиторий и перейдите в него:

   ```bash
   git clone https://github.com/YuriChe/mle-razrabotka-v-ide.git
   cd mle-razrabotka-v-ide
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   # Windows (PowerShell)
   python -m venv venv
   .\venv\Scripts\Activate.ps1

   # Linux / macOS
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Установите зависимости из `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

## Как запустить

Из корня проекта (при активированном окружении):

```bash
python main.py
```

Программа прочитает `data/payments.csv` и выведет два отчёта с разными
настройками форматирования.
